# Bank Management System

A simple **Bank Management System** built with **Python and Streamlit**. It allows users to create and manage a bank account through a simple web interface.

## Features

* Create a new bank account
* Generate a unique account number
* Deposit money
* Withdraw money
* Check account details
* Update account information
* Delete an account
* Store account data in `data.json`

## Technologies Used

* Python
* Streamlit
* JSON
* Random
* Pathlib

## Project Structure

```text
Bank-Management-System/
│
├── app.py
├── data.json
└── README.md
```

## How to Run

### 1. Install Streamlit

```bash
pip install streamlit
```

### 2. Run the application

```bash
python -m streamlit run app.py
```

The application will open in your web browser.

## Data Storage

Account information is stored locally in `data.json`. No external database is required.
